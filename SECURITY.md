# Security

This is a research prototype for controlled local evaluation. Protect provider keys, passwords, browser sessions, private welcome pages, local account files and SQLite journals. Do not attach them to public issues or commit them.

For a suspected vulnerability, open a public issue containing only a request for a private reporting channel, or use GitHub private vulnerability reporting if enabled. Share technical details privately after a channel is established. No response-time guarantee or managed disclosure service is claimed.

The default app listens locally. Hosted use requires the origin, authentication, persistent storage and owner-funded inference configuration documented in [hosting](docs/hosting.md). Review generated release assets before publication. Local credential scanning is heuristic, not an exhaustive guarantee.

A model verdict is not a security boundary. Independent validation, exact approvals and ownership checks remain required. Safety Lab cases operate in a separate simulation and do not modify Operations workflows.
