## Where each item goes

- **GitHub repository:** extracted source, README, MIT LICENSE, app/, docs/, scripts/, CI and deployment recipes. Exclude secrets, private accounts, local journals, logs and generated run directories.
- **GitHub Release:** source ZIP and Orkestryn.pyz from the same verified commit. Use its actual public URL for the downloadable test build.
- **YouTube:** actual public demonstration recording, under three minutes. Never show keys or generated passwords.
- **Devpost:** actual repository URL, working-project URL, video URL, project text, track, tool feedback and complete testing instructions. Use the private testing fields/channel for credentials when appropriate; do not publish provider keys in source or public descriptions.
- **Local machine only:** account databases, .safety_lab journals, private welcome pages and owner credentials.
