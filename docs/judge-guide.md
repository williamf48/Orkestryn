# Judge walkthrough

From the source repository run `python run.py --demo --console`, or use START_DEMO.cmd on Windows. From a GitHub Release run `python Orkestryn.pyz`; choose Open judge evaluation. Python 3.10+ is required. The private welcome page generated on your computer provides judge-admin login details. It contains credentials and must not be uploaded or recorded.

Choose Create a workflow → Free scripted rehearsal → Balanced → 60 minutes for the free path. Review the batch, start observation, separately review the development fault and recovery, complete manager and customer handoff reviews, then release only the permitted finished customer job. Inspect the outcome report. Finally stop the observer and owned workers using their separate controls and export evidence.

The judge account includes every demo role for convenience. Two reviews by this account are separate recorded operations, not two-person authorization. Separate generated role accounts are also available. The judge workspace is separate from the main workspace.

NVIDIA mode uses Nemotron through Nebius Token Factory. Each proposal and Safety Lab model request needs its own review; failed or uncertain requests are retained and never automatically retried. Keys entered privately remain in server session memory, not saved evidence. Sign-in and workflow timers are separate; refreshing renews neither.

In Safety Lab, Compare controls performs a free authored evaluation. Case browser inspects individual plans. Model requests optionally obtains one live candidate or monitor reply after review. A REPLIED status proves only a syntactically valid saved reply; use Evaluate selected candidate to score its simulated effects separately. Export through Results & exports.

Submission-owner task: provide an actual public release URL and a working owner-funded live access method in the private testing instructions. A placeholder or instruction to buy credits is insufficient. The repository includes hosting and scoped-relay recipes, but they are not deployed automatically.
